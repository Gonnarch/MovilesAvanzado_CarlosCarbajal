# Laboratorio 06 — Navegación y cliente

Autor: Carlos Daniel Carbajal Durand.

Esta rama contiene el avance previo a la calculadora: proyecto UIKit, icono del astronauta, Navigation Controller, PANTALLA 1 y PANTALLA 02, registro de cliente y confirmación modal.

Abre `laboratorio06.xcodeproj` y ejecuta el esquema `laboratorio06` en un simulador. El esquema `Semana06_02` abre directamente el formulario del cliente. La compilación y la ejecución deben verificarse en Xcode.

La carpeta mantiene el ejercicio denominado manual por la guía; el código de esta entrega se preparó con ayuda de IA. La calculadora, PROMPTS.md y la documentación completa están en las ramas `ai-assisted` y `main`.
