Cómo reproducir

El archivo CSV contiene las entradas modificadas respecto del ejemplo base. Antes de cada prueba: General 728; confirmación, mes mínimo y jornada = Sí; RIA y cese = No; meses = 6; días y ausencias = 0; sueldo = 3000; gratificación = 3000; otros componentes = 0; principal fija; total variable = 18000; divisor = 180; tope restante = 90; básica agraria = 1230; días agrarios = 30; complementos = seis ceros. Luego aplicar las modificaciones y comparar.

Casos C: los identificadores corresponden a la hoja CTS. Casos A: la sección asistente corresponde a Fechas y gratificación y cts a CTS; el número representa la fila B. Las fechas se registran como número serial Excel. Antes de cada caso A, restablecer modos Manual, ingreso 01/01/2026, inicio 01/05/2026, corte 31/10/2026, RC histórica 3000, meses 6, faltas 0 y confirmación No. “null” significa borrar la celda. Las seis variables corresponden a D10:I10. Si están vacías en la columna de modificaciones, se conservan los seis ceros del caso base.
